# Especificações da Faculdade — Projeto M1

## 4. Requisitos Obrigatórios da Faculdade

### 4.1 Entidades de Informação

A entidade ou conjunto de entidades utilizado deve possuir **pelo menos 10 atributos**.

### 4.2 Design Patterns

O projeto deve ser desenvolvido de acordo com os Design Patterns estudados em sala de aula.

Os padrões explicitamente considerados nos critérios de avaliação são:

- **DAO**
- **MVC**
- **COMMAND**
- **FACTORY METHOD**
- **BUILDER**

A utilização correta desses padrões vale **2,0 pontos**.

### 4.3 Funcionalidades Obrigatórias

O sistema deve implementar as seguintes operações:

- Inserir;
- Deletar;
- Atualizar;
- Consultar por ID;
- Consultar todos;
- Uma funcionalidade que automatize algum processo de negócio.

As funcionalidades propostas pelos estudantes devem ser aprovadas pelo professor.

### 4.4 Relacionamentos

O projeto deve conter funcionalidades que envolvam a implementação dos seguintes tipos de relacionamento entre as entidades:

- **1:1 (um para um)**
- **1:N (um para muitos)**

A implementação correta dos relacionamentos vale **0,5 ponto**.

### 4.7 Usabilidade

O projeto deve apresentar boa usabilidade.

Esse item vale **0,5 ponto**.

### 4.8 Qualidade do Código

O projeto será avaliado quanto ao nível de conformidade com:

- **SOLID**
- **Object Calisthenics**
- **Coesão**
- **Acoplamento**

Esse item vale **0,5 ponto**.



### Observações da avaliação

- Projetos identificados como cópia ou feitos por IA serão avaliados com **0 (zero)**.
- O teto da nota do projeto é **3,0 pontos**.
